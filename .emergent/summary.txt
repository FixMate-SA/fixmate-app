<product_requirements>
FixMate-SA is a mobile/web application connecting clients with fixers, featuring user authentication, job management, fixer profiles, and rating systems, supporting non-smartphone users via SMS/MMS (USSD) and a learning platform.

The primary goal is to establish a robust FixMate Job Request and Assignment Workflow. This workflow mandates client terms acceptance before job submission and includes a multi-step process:
1.  **Request Logging**: Client submits/cancels requests.
2.  **Real-Time Fixer Screening**: Identifies closest, available fixers (/bin/bash debt, ≥3.0 rating or new 0.0 rating, available status).
3.  **Notification & Acceptance**: Qualified fixers receive app/WhatsApp notifications; first-come-first-served acceptance, with cancellation options.
4.  **Client Updates & Tracking**: Client receives fixer details and real-time tracking; can cancel until fixer arrival.
5.  **Timeout Handling**: If fixer doesn't arrive within 180 minutes, job is flagged EMERGENCY, reassigned, and original fixer is marked unavailable (4-hour freeze).
6.  **Job Completion Protocol**: Post-service, client rates fixer, provides feedback; R20 platform fee is automatically deducted. Admins can override incomplete jobs.
7.  **AI-Powered Fraud Prevention**: Monitors fixers for patterns (>3 failures/week, <65% completion, >25% cancellation) triggering admin alerts.
8.  **Fair Matching Algorithm**: Prioritizes proximity, user rating, availability, and historical performance.
9.  **Cancellation Protocols**: Fixer cancellation (2-hour freeze, 0.2 rating penalty), Client cancellation (immediate job release, no fees). Both receive notifications.
10. **Fixer Constraints**: Only one active job; must complete current job before new requests; outstanding balances block eligibility; 48-hour suspension for unpaid fees.
11. **Admin Override Privileges**: Can bypass restrictions for non-fault failures, false reports, or emergencies; can manually reset status/ratings.
Additionally, the user requested permanent removal of Phase 3, PWA Status, and Performance features from the application.
</product_requirements>
