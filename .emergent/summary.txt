<product_requirements>
FixMate-SA aims to be a mobile/web application connecting clients with fixers, leveraging an existing WhatsApp system's PostgreSQL database. Core features include user authentication (phone/password), job, fixer, and rating management. Future enhancements encompass voice interaction (Google Gemini), PayFast payments, and business insights. Support for non-smartphone users via SMS/MMS (USSD) and a learning platform for fixers are also required, alongside general UI/UX improvements.

- Full support for all 11 South African official languages.
- A fixer payment system preventing job allocation for fixers owing a R20 service fee.
- An Admin verification portal for fixer ID document submission and background checks.
- An Emergency/Panic Button for users/fixers to alert police with location.
- Enhanced AI job matching for fairness and efficiency.
- Password-based authentication for all user roles (client, fixer, admin) and an enhanced signup process for full name, ID number, and town/municipality.
- A robust fixer vetting process before job allocation.
- Integration of a legacy  (WhatsApp, Gemini, PayFast, job matching, location, voice transcription, data analytics, fee management, conversation state, admin commands) into the FastAPI architecture.
